# 🚀 Featured Projects

## 🛠️ TopSoundBD - Full-Stack Audio & Sound System E-Commerce Platform
TopSoundBD is a modern full-stack e-commerce web application focused on selling audio and sound system products in Bangladesh. The platform provides a smooth shopping experience for customers and powerful management tools for administrators.

🌐 **Live Site:** [topsoundbd.com](https://topsoundbd.com/)  
📦 **GitHub Repository:** [TopSoundBD](https://github.com/aliftareq/Top_sound_ecommerce)  
🔑 **Server API:** [API Link](https://api.topsoundbd.com/)

### Key Features

**👤 User Features**
- Product Browsing: Explore a wide range of sound systems, speakers, microphones, and audio accessories.  
- Category Filtering: Browse products by category, brand, or price.  
- Product Details: View detailed product descriptions, specifications, and pricing.  
- Shopping Cart: Add, update, or remove products from the cart.  
- Checkout & Orders: Place orders smoothly with order tracking.  
- User Dashboard: View order history, manage profile information, track order status.  
- Authentication: Secure user registration and login system.  

**🛠️ Admin Features**
- Product Management: Add, update, delete, or hide products.  
- Order Management: View and update customer orders.  
- User Management: View registered users and assign admin roles.  
- Admin Dashboard: Overview of total users, products, and orders; basic sales insights.

## 🛠️ Dentcare - AI-Assisted Dental Care Platform
Dentcare is a cutting-edge AI-powered platform designed to facilitate dental care consultations and management through a seamless web application. The platform provides real-time consultations, an efficient patient management system, and secure appointment scheduling for both patients and doctors.

🌐 **Live Site:** [Dentcare Live](https://dentcare-seven.vercel.app/)  
📦 **GitHub Repository:** [Dentcare](https://github.com/aliftareq/Dentcare)  
🔑 **Server API:** Dentcare API

### Key Features

**👤 User Features**
- AI-Powered Voice Assistant: Engage with an AI-powered voice assistant to discuss dental issues and receive real-time consultations.  
- Appointment Booking: Schedule appointments with preferred doctors at available times.  
- Secure Transactions: Integrated Stripe payment gateway for secure payments.  
- User Dashboard: View appointment history, manage personal information, track ongoing consultations.  
- Consultation History: Access past consultation records, advice, and doctor recommendations.  

**🛠️ Admin & Doctor Features**
- Patient Management: View and manage patient profiles and track progress.  
- Appointment Management: Approve, reschedule, and manage upcoming appointments.  
- Role-Based Access: Admins can manage doctor and patient roles.  
- Admin Dashboard: Overview of total users, appointments, consultations, and revenue; insights on platform usage.
